此目录存放一些静态文件，用于公网访问。

你也可以通过 `https://file.opensrv.cloud/<文件名>` 访问存放在我云服务器的静态文件。

**访问链接**

1. GitHub 链接 - `https://github.com/Ryna755467/static/blob/main/<文件名>`
   打开 GitHub 的文件预览页面。

2. raw 直链 - `https://raw.githubusercontent.com/Ryna755467/static/main/<文件名>`
   在浏览器中直接打开文件。

3. CDN 链接 - `https://cdn.jsdelivr.net/gh/Ryna755467/static@main/<文件名>`
   通过 jsDelivr CDN 加速访问。

> jsDelivr 是一个免费的公共 CDN，专门为 GitHub、npm 等开源资源提供加速。
> 
> 更新文件后，CDN 不会立刻同步，通常需要几分钟到几小时。
